3. Các thanh ghi RCC quan trọng
Thanh ghi	Chức năng
RCC_CR		Bật/tắt HSI, HSE, PLL
RCC_PLLCFGR	Cấu hình hệ số PLL
RCC_CFGR	Chọn nguồn clock hệ thống và chia clock
RCC_CIR	Quản lý ngắt clock
RCC_AHB1RSTR	Reset ngoại vi trên AHB1
RCC_AHB2RSTR	Reset ngoại vi trên AHB2
RCC_APB1RSTR	Reset ngoại vi trên APB1
RCC_APB2RSTR	Reset ngoại vi trên APB2
RCC_AHB1ENR	Cấp clock cho ngoại vi AHB1
RCC_APB1ENR	Cấp clock cho ngoại vi APB1
RCC_APB2ENR	Cấp clock cho ngoại vi APB2
